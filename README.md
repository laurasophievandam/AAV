# CMV-pp65 cross-reactive ANCA-specific B cells link CMV to ANCA-associated vasculitis

Data analysis code for paper "CMV-pp65 cross-reactive ANCA-specific B cells link CMV to ANCA-associated vasculitis".

1. Dependent R packages developed with the paper:

- [screceptor](https://github.com/zhangzmr/screceptor): **Used for BCR analysis in this paper.** Single-cell BCR/TCR repertoire processing (clonal clustering, germline reconstruction, SHM, merge with GEX)
- [scgtest](https://github.com/zhangzmr/scgtest): **Used for pseudobulk DE testing in this paper.** Differential expression testing for single-cell and pseudobulk RNA-seq (edgeR, RUV, pathway enrichment)
- [bioscrna](https://github.com/zhangzmr/bioscrna): Bioconductor-based single-cell RNA-seq pipeline (loading, QC, normalization, clustering, markers)
